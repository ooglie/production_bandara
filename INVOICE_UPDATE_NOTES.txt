Bandara final invoice / GST snapshot update
===========================================

This package is incremental to the previously delivered UI, checkout and
order/invoice-numbering updates.

Apply from the Laravel project root, then run:

  php artisan optimize:clear
  php artisan migrate
  php artisan test --filter=InvoiceTaxSummaryServiceTest
  php artisan test

Before generating production invoices, set the SAC codes confirmed by your CA:

  DELIVERY_SAC_CODE=
  HANDLING_SAC_CODE=

The update does not change the invoice PDF storage disk or folder logic.
Existing stored PDFs are not overwritten automatically. New invoices use the
new layout. An older invoice uses the new layout only when its PDF is force
regenerated.
